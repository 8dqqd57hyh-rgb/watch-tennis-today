# GSC: Crawled — currently not indexed

Проверка 21.09.2026 для отчёта с неудачной валидацией 18–19.09.2026.
Доступа к самой GSC и сохранённому Google HTML нет: даты валидации предоставлены
пользователем. Причина решения Google о неиндексации не установлена.

## Подтверждённые результаты production до изменений

Проверено ограниченной командой `npm run test:e2e:prod-smoke`: GET без
автоматического следования редиректам, HTML без JavaScript, robots.txt и sitemap.

| URL | HTTP / переход | Canonical | Robots / X-Robots-Tag | Sitemap |
| --- | --- | --- | --- | --- |
| `/watch` | 200, без редиректа | собственный | meta отсутствует / заголовок отсутствует | есть |
| `/player/alexander-zverev` | 200, без редиректа | собственный | index, follow / заголовок отсутствует | есть |
| `/player/zverev-alexander` | 308 → `/player/alexander-zverev` → 200 | используется целевой URL | отдельная индексируемая страница не нужна | нет |
| `/disclaimer` | 200, без редиректа | собственный | meta отсутствует / заголовок отсутствует | есть |

Отсутствие meta robots означает отсутствие запрета индексации. Robots.txt разрешает
публичные URL и указывает `https://watchtennistoday.com/sitemap.xml`; запреты касаются
API, служебных ресурсов и подтверждения подписки. Основной текст доступен без JS:
около 1780 символов у `/watch`, 4024 у профиля и 1716 у `/disclaimer`.
Признаков пустого шаблона или soft 404 в проверенных HTML не обнаружено; классификацию
Google soft 404 без URL Inspection проверить нельзя.

## Ошибки и изменения

- Fallback `playerMatches[0]` делал завершённый матч следующим; в production в поле
  Next opponent был соперник завершённого матча. Удалён fallback. При отсутствии
  актуальных матчей показывается явное сообщение, профиль остаётся доступным.
- Широкое условие upcoming включало отменённые, отложенные и неизвестные статусы.
  Теперь допускаются только нормализованные LIVE/UPCOMING с корректной датой.
  Сохранены пороги API: 8 часов для LIVE и 12 часов для запаздывающего расписания.
  Отсутствие актуальной записи не означает отмену матча в реальном мире.
- Предстоящие матчи сортируются по времени независимо от названия статуса;
  результаты — от новых к старым, отсутствующие даты — после датированных.
  Завершённый счёт исключает ложный LIVE/UPCOMING. Незавершённые сеты и два выигранных
  сета в мужском основном турнире Grand Slam не считаются завершённым матчем.
- Уведомление о следующем матче и FAQ используют один результат выбора. В текущем
  компактном профиле FAQ JSON-LD не выводится; исправлен также код альтернативного
  полного представления. Структурированные SportsEvent берутся из отфильтрованного
  расписания. Панели активности используют ту же классификацию матчей.
- Исторический турнир больше не выдаётся за текущий; текущий live-соперник подписан
  Current opponent. Служебная фраза о «indexable editorial context» заменена
  подсказкой зрителю о подаче, бэкхенде и позиции на корте, без новых биографических фактов.
- Карточка стран `/watch` теперь ведёт на существующий `/watch-tennis-in` (200),
  а не сразу на Польшу. Заголовок уточняет роль страницы: Tennis Viewing Directory.
- В данных `/atp-live-today` заменён slug `zverev-alexander` на канонический.
  Постоянный редирект сохранён. Поиск по исходникам app/data/src больше не находит
  этот alias в контентных ссылках.

## Назначение страниц и внутренние ссылки

`/watch` — короткий каталог переходов: live, ТВ-расписание, страны, легальный просмотр.
`/watch-tennis-in` — выбор страны; `/watch-tennis-online` и
`/how-to-watch-tennis-legally` — объясняющие руководства;
`/tennis-tv-broadcast-finder` — поиск вещателя. Тематика пересекается, но полное
дублирование назначения и контента не подтверждено: `/watch` сохранён отдельно.
На него ссылаются в том числе `/grand-slam-live`, `/how-to-watch-tennis-without-cable`
и хлебные крошки `/watch/[slug]`. Профили получают канонические ссылки из каталога
игроков и связанных игроков. `/disclaimer` связан из общего footer.

`technicalSeo.ts` не исключает три канонические страницы. Metadata Зверева использует
`shouldIndexPlayerPage` из `adsenseIndexing.ts`: канонический slug входит в reviewed
allowlist, профиль проходит проверку наполнения. `sitemap.ts` нормализует slug и
использует этот allowlist, поэтому основной профиль включён, alias исключён.
У `/watch` и `/disclaimer` нет noindex, они присутствуют в статическом списке sitemap.
Противоречий правил для этих четырёх адресов не обнаружено. Правила индексации и
lastmod не менялись.

**У `/disclaimer` технических проблем не выявлено.** Страница не изменялась;
отсутствие юридической страницы в поиске само по себе не требует исправления.

Исправления повышают точность страницы, но не устанавливают причину неиндексации.
